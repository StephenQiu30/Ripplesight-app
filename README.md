# Ripplesight App

Ripplesight App 是 Ripplesight 的 Flutter 客户端预留仓库。**当前已冻结**：还没有初始化 Flutter 工程，只有工程约定，没有可以运行的应用。

Ripplesight 是面向个人非商业使用的公开资讯阅读与舆情监控项目，围绕关键词连接来源材料、讨论与事件进展。后端和 Web 在 [Ripplesight 主仓库](https://github.com/StephenQiu30/Ripplesight)，产品需求与实际进度以那边的 `workspace/content/` 和 `BACKLOG.md` 为准。本机目录为 `Ripplesight/ripplesight-app/`。

恢复开发前，请先阅读 [PROJECT](PROJECT.md) 和 [AGENTS](AGENTS.md)。参与方式见 [CONTRIBUTING](CONTRIBUTING.md)，安全问题见 [SECURITY](SECURITY.md)。本项目采用 [MIT 许可证](LICENSE)。
